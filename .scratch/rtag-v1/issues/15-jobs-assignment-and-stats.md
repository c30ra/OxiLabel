# 15: Jobs, assignment and statistics

**What to build:** Admins split a Project's images into Jobs and assign each to an annotator. Annotators see only their jobs, own them, and a Job's owner is enforced when saving. A statistics view shows annotation counts per label, job and user.

**Blocked by:** 03, 14

**Status:** ready-for-agent

- [ ] I can create a job from selected images or a filter and assign it to an annotator
- [ ] An annotator sees their assigned jobs and can only edit images in jobs they own
- [ ] Admins can see and edit all jobs and reassign them
- [ ] The statistics screen shows annotation counts per label, per job and per user
- [ ] API tests cover job ownership enforcement on annotation saves
