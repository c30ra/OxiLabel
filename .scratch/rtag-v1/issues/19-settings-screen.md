# 19: Settings screen

**What to build:** A per-user settings screen with remappable keyboard shortcuts, pie menu sensitivity (flick distance), the label-switch style (number hotkeys plus label-ring key, or a label slice in the options ring), and light or dark theme. Settings are stored on the server and follow the user.

**Blocked by:** 07, 14

**Status:** ready-for-agent

- [ ] I can rebind shortcuts, and conflicting bindings are flagged
- [ ] Changing pie sensitivity changes how far I must flick, with immediate effect
- [ ] The label-switch style setting changes how labels are switched in editing mode
- [ ] Theme choice applies immediately
- [ ] Settings persist across sessions and machines for the same account
